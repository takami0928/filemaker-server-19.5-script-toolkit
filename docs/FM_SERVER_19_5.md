# FileMaker Server 19.5 実行境界

## 基本モデル

FileMaker Server上で実行されるFileMakerスクリプトは、FileMaker Script Engine（FMSE）の独立セッションで動く。クライアント側の状態を引き継ぐ処理として設計してはならない。

サーバー側で再構築すべき代表的な状態:

- 対象ファイル
- レイアウトと基準TO
- 対象レコードまたは対象集合
- ソート順
- ローカル変数、グローバル変数
- グローバルフィールド
- 開いている関連ファイル

## 互換性

各スクリプトステップは、FileMaker Pro 19.5のスクリプトワークスペースで「互換性: サーバー」を確認する。サーバー非対応ステップは、通常エラー3となりスキップされ得るため、生成段階で排除する。

## 19.5固定

本リポジトリでは、後続バージョンで追加された機能を使用しない。特に、ネイティブのトランザクション系ステップやコールバック付きPSOSなど、19.5に存在しない機能を提案しない。

## サーバースケジュール

- スケジュールで指定したアカウントで実行される。
- タイムアウト、同時実行、再実行時の重複を考慮する。
- Event.logに残る情報だけに依存せず、業務処理ログを用意する。
- 外部ファイル、ファイルパス、ODBC、プラグインはサーバー環境で再確認する。

## 開発時の確認

- FileMaker Serverの正確な19.5.xビルド
- FileMaker Proの正確な19.5.xビルド
- Windows Serverのバージョン
- 使用プラグインと64bit対応
- PSOS同時セッション設定
- スケジュールの実行アカウント
- 対象ファイル間の認証と外部データソース
