# 既知の制約

- `fmxmlsnippet`は一般的な公開APIとして完全仕様化された形式ではない。
- 初期レンダラーは少数の制御・変数ステップだけを対象とする。
- フィールド、レイアウト、スクリプト参照を伴うステップは、対象ファイル固有のID解決が必要である。
- Script IR v2は未解決オブジェクト参照を保持できるが、内部IDが解決されるまでXMLを生成しない。
- v1移行では、元の形式に存在しない実行モード、契約、コンテキスト、目的、副作用を未指定として保持する。完全なv2設計にするには人間による補完が必要である。
- v2の厳格な設計情報をXMLへ直接埋め込むわけではなく、現在のレンダラー出力は既存7ステップに限定される。
- Windowsクリップボード機能はWindows上でのみ実機検証できる。
- FileMaker Pro 19.5のパッチ差により、XMLやクリップボード形式に差がないことを実機で確認する必要がある。
- FileMakerへの貼り付けが成功しても、参照先、権限、実行コンテキスト、サーバー互換性は別途確認が必要である。
- 本ツールはレイアウト、テーブル、リレーション、権限セットを生成しない。
- AIが社内文書を誤読した場合、本ツールは業務要件の誤りを自動修正できない。
