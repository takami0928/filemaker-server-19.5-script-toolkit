# 目的と責任範囲

## 一文での定義

本リポジトリは、AIが社内文書から取得したシステム固有情報をもとに、FileMaker Server 19.5に適合した、シンプルで読みやすく、保守しやすく、安定動作するFileMakerスクリプトを設計し、検証済みXMLとしてFileMaker Pro 19.5のスクリプトワークスペースへ貼り付けるための、公開技術リファレンス兼スクリプト補助ツールである。

## 担う役割

- FileMaker Server 19.5における実装方法をAIへ与える。
- サーバーサイド実行のコンテキスト、互換性、エラー処理の癖を集約する。
- 業界で広く使われるFileMakerスクリプト作法を、判断可能な規則へ変換する。
- AIのスクリプト案を、FileMaker Proへ貼り付け可能な`fmxmlsnippet`へ変換する。
- 未検証のステップXMLを推測生成せず、実物フィクスチャに基づいて拡張する。
- 人間の手入力と基本的なレビュー負担を減らす。

## 担わない役割

- 社内のテーブル定義、画面遷移、レイアウト、業務ルールの保管
- `.fmp12`ファイルの管理
- FileMaker Serverの運用監視、バックアップ、アカウント管理
- 本番環境への自動変更
- レイアウトやリレーションシップグラフの完全自動生成
- 実機テストの代替
- 生成結果の無条件な正しさの保証

## 情報の分担

### 社内文書が答えること

- 何を実現するか
- どのテーブル、フィールド、TO、レイアウトを使うか
- どの画面から、誰が、どの権限で呼び出すか
- 現行実装と変更要件は何か

### 本リポジトリが答えること

- FileMaker Server 19.5でどう実装するか
- クライアントとFMSEのどちらで処理するか
- 引数、戻り値、変数、エラー処理をどう構成するか
- コンテキストをどう再構築するか
- どのXMLを生成でき、どこから先は実物フィクスチャが必要か
- 何を確認すれば「実装可能」「動作確認済み」と言えるか
